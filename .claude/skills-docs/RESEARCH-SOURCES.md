# Research Sources Used to Build This Skill System

The skills were synthesized from four source families requested by the project owner:

## 1. Anthropic / Agent Skills
Anthropic's official Agent Skills repository and the Agent Skills specification establish the packaging model, `SKILL.md` contract, progressive disclosure, and examples. Claude Code documentation governs current harness behavior.

## 2. Open-source engineering skill libraries
Research inputs include obra/superpowers, Everything Claude Code, SteveVitali/agent-skills, Jeffallan/claude-skills, swell-agents/coding-skills, CODE-SAURABH/OpenSkills, S7adows/production-ready-claude-skills, agentik-os/claude-code-skills, and vercel-labs/agent-skills. These were treated as practitioner patterns: workflows, routing, review methods, TDD, evidence, independent agents, progressive disclosure, and domain-specialist decomposition.

## 3. YC / Product
The community `jona/ycombinator-skills` repository and product-skills synthesis were used for problem discovery, customer evidence, smallest complete outcomes, rapid learning, AI-accelerated iteration, and product/engineering feedback loops. YC-style speed is constrained by security, privacy, correctness, accessibility, reliability, compliance, and safety requirements.

## 4. Industry standards and official guidance
The corpus includes OWASP Top 10:2025, OWASP API Security Top 10:2023, OWASP ASVS, NIST SSDF, NIST AI RMF/GenAI Profile, W3C WCAG 2.2, Google Web Vitals, ISO/IEC 25010:2023, C4, arc42, DORA, OpenTelemetry, SLSA v1.2, OpenSSF Scorecard, Kubernetes security guidance, Terraform style/workflow guidance, Twelve-Factor App, IIBA BABOK, and IETF RFC 9457.

## Source-use rule

These sources are ingredients, not mandates to be copied wholesale. Normative standards outrank community opinions. Official documentation outranks stale examples for fast-moving technology. Community install/star counts can reveal demand and discoverability, but do not establish technical correctness.

See `references/source-registry.md` for the full registry and `references/` for the distilled cross-cutting practices.
