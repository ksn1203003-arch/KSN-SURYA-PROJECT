# Source Registry

This registry is the research corpus used to build the skills. It is intentionally a synthesis map, not a copy of source content.

## Source weighting
1. Law/regulation/policy when binding
2. Standards/specifications
3. Official documentation
4. Mature open-source engineering practice
5. Practitioner/community sources
6. Popularity/install signals

Never treat GitHub stars, installs, or a community skill as proof that a practice is universally correct. Use them to discover patterns, then validate the pattern against the project and stronger sources.
